# Snake Game

Jogo da cobrinha feito em aula no curso de desenvolvimento do SENAI, com o Prof. Ewerton Cercal.

HTML, CSS e JavaScript puros, sem biblioteca nenhuma.

## O que tem

- Menu com o maior recorde salvo no navegador (`localStorage`).
- Três velocidades: lenta, normal e rápida.
- Tabuleiro 20x20 controlado pelas setas, pelo WASD ou pelos botões na tela (celular).
- Cada fruta vale 10 pontos. Bater na borda ou no próprio corpo encerra a partida.
- Tela de fim de jogo com opção de jogar de novo ou voltar ao menu.

## Como executar

Abra o arquivo `src/index.html` no navegador, escolha a velocidade e clique em "Começar".
